Learning Stack

Materiale didattico per l'insegnamento dell'Informatica nel triennio degli istituti tecnici tecnologici — pubblicato come sito consultabile su luisalealirizzi.github.io/learning_stack.

Cosa contiene

Percorsi didattici organizzati per anno e materia:

Linguaggio C (terzo anno): selezione, cicli, vettori, funzioni, puntatori
Java e programmazione a oggetti (quarto anno): OOP, principi SOLID
Basi di dati e SQL (quinto anno): modellazione, query, integrazione con applicazioni Java (JDBC/Hibernate)

Ogni argomento è pensato per essere autosufficiente: spiegazione concettuale, esempio concreto, errori tipici da evitare, esercizi progressivi.

Metodo didattico

Il materiale segue uno stile costante, pensato per rendere concetti astratti concreti fin dalla prima lettura:

Blocchi numerati: ogni argomento è scomposto in passaggi osservabili, non in spiegazioni monolitiche
Schemi mentali: prima di ogni nuovo costrutto, un modello concettuale su cui ancorare il dettaglio tecnico
Errori classici evidenziati: ogni sezione include gli errori più comuni, con il confronto diretto tra codice sbagliato e codice corretto
Famiglie di esercizi progressivi: dagli esercizi di base fino a esercizi di riepilogo che combinano più concetti

Il materiale nasce dall'uso quotidiano in aula ed è aggiornato in base a cosa funziona davvero con gli studenti, non da un programma teorico astratto.
